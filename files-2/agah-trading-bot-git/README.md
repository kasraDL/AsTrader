# میز معاملاتی آگاه (Cloudflare Worker)

وب‌اپ شخصی برای دیدن نمادهای بورس ایران از روی توکن سامانه آنلاین آگاه، تحلیل واچ‌لیست، و در صورت تمایل ارسال سفارش با سقف ریسک.

## واقعیت‌های مهم

- API آگاه **غیررسمی** است و ممکن است بدون اطلاع عوض شود.
- لاگین آگاه عمداً دستی است (کپچا). ربات کپچا را دور نمی‌زند.
- ورود به این داشبورد با **توکن Bearer** بعد از لاگین خودتان در `online.agah.com` انجام می‌شود.
- اسکن و معامله خودکار **فقط روی واچ‌لیست** است، نه روی تمام نمادهای بازار. دیدن همه نمادها در تب بازار ممکن است.
- هیچ استراتژی داخلی سود را تضمین نمی‌کند. SMA + RSI یک فیلتر ساده است.
- اتوماسیون پیش‌فرض **خاموش** است. تا وقتی روشن نکنید، سفارش فقط بعد از تایید دستی ارسال می‌شود.
- سقف ارزش سفارش (`maxOrderValueRial` / `MAX_ORDER_VALUE_RIAL`) جلوی سفارش بزرگ را می‌گیرد.

## معماری

```
مرورگر  --توکن-->  Worker  --Bearer-->  tseonlineapi / tsembdpapi آگاه
                         |
                        KV  (توکن، نشست، واچ‌لیست، تنظیمات، سیگنال، لاگ)
                         |
                   Cron هر ۵ دقیقه در ساعات بازار
```

## راه‌اندازی

```
npm install -g wrangler
wrangler login
wrangler kv namespace create BOT_KV   # اگر id عوض شد در wrangler.toml بگذارید
wrangler deploy
```

اختیاری:

```
wrangler secret put DASHBOARD_PASSWORD
wrangler secret put AGAH_USER_IDENTIFIER
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID
```

اگر `DASHBOARD_PASSWORD` ست باشد، همان مقدار هنوز به‌عنوان کلید API قدیمی کار می‌کند. مسیر اصلی ورود، توکن آگاه است.

## استفاده

1. در مرورگر وارد `online.agah.com` شوید و کپچا را حل کنید.
2. از Network یک درخواست بعد از لاگین را باز کنید و مقدار `Authorization: Bearer ...` را کپی کنید.
3. اگر هدر `UserIdentifier` دیدید آن را هم وارد کنید.
4. داشبورد Worker را باز کنید، توکن را بگذارید و وصل شوید.
5. در تب بازار نمادها را ببینید، به واچ‌لیست اضافه کنید، نمودار و سیگنال را چک کنید.
6. برای معامله خودکار: تب اتوماسیون → سقف‌ها را تنظیم کنید → ارسال خودکار را روشن کنید.

توکن معمولاً چند ساعت بیشتر عمر ندارد؛ هر روز صبح باید تازه شود.
