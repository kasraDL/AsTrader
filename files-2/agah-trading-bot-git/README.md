# میز معاملاتی نیمه‌خودکار آگاه (Cloudflare Worker + وب‌اپ)

## قبل از هرچیز

- این پروژه از یک API **غیررسمی** (reverse-engineered) کارگزاری آگاه استفاده می‌کنه، نه یک API مستند و پشتیبانی‌شده. یعنی ممکنه هر زمان بدون اطلاع قبلی تغییر کنه و ربات از کار بیفته.
- ورود (لاگین) عمداً **دستی** نگه داشته شده چون آگاه از کپچا + یک لایه رمزنگاری‌شده device-fingerprint استفاده می‌کنه که برای جلوگیری از ورود خودکار طراحی شده. این پروژه اون لایه رو دور نمی‌زنه.
- هر سفارش نیاز به **تایید دستی تو از داخل وب‌اپ** داره — چیزی خودکار سفارش نمی‌زنه.
- یک سقف ارزش سفارش (`MAX_ORDER_VALUE_RIAL`) در کد قفل شده که مستقل از سیگنال، جلوی سفارش‌های بزرگ رو می‌گیره.
- داشبورد پشت یه رمز عبور (`DASHBOARD_PASSWORD`) قفله. این تنها لایه محافظتی وب‌اپه، پس رمز قوی انتخاب کن و لینک Worker رو جایی عمومی share نکن.

## معماری

```
مرورگر (داشبورد وب - public/index.html)
        |  fetch با هدر X-Dashboard-Key
        v
Cloudflare Worker (src/index.js)  <-->  KV (توکن، واچ‌لیست، سیگنال‌های در انتظار، لاگ)
        |
   Cron Trigger (هر ۵ دقیقه در ساعات بازار)
        |
tsembdpapi.agah.com/.../TradingViews/history  (کندل روزانه)
        |
موتور سیگنال (SMA crossover - قابل تعویض با AI بعداً)
        |
سیگنال در KV می‌شینه، در وب‌اپ نمایش داده می‌شه (+ پیام تلگرام اختیاری)
        |
(بعد از تایید در وب‌اپ) tseonlineapi.agah.com/api/v1/order
```

## راه‌اندازی

1. **نصب wrangler و لاگین به کلادفلر:**
   ```
   npm install -g wrangler
   wrangler login
   ```
2. **ساخت KV namespace:**
   ```
   wrangler kv namespace create BOT_KV
   ```
   عدد `id` که برمی‌گردونه رو توی `wrangler.toml` جای `REPLACE_WITH_KV_ID` بذار.
3. **تنظیم secretها:**
   ```
   wrangler secret put DASHBOARD_PASSWORD
   wrangler secret put AGAH_USER_IDENTIFIER
   ```
   یه رمز قوی برای `DASHBOARD_PASSWORD` انتخاب کن. مقدار `AGAH_USER_IDENTIFIER` رو از هدر `UserIdentifier` که توی HAR دیدی بردار.

   (اختیاری، برای دریافت پیام تلگرام وقتی سیگنال جدید میاد:)
   ```
   wrangler secret put TELEGRAM_BOT_TOKEN
   wrangler secret put TELEGRAM_CHAT_ID
   ```
4. **دیپلوی:**
   ```
   wrangler deploy
   ```
   خروجی یه آدرس مثل `https://agah-trading-bot.<subdomain>.workers.dev` می‌ده — همینو باز کن.

## استفاده روزانه

1. آدرس Worker رو باز کن، رمز داشبورد رو وارد کن.
2. هر روز صبح قبل از باز شدن بازار، توی یه تب دیگه دستی وارد online.agah.com بشو، کپچا رو حل کن.
3. توکن Bearer تازه رو از Network tab مرورگر (یکی از درخواست‌های بعد از لاگین، نه خود authenticate) بردار و توی بخش «توکن آگاه» داشبورد بریز، ذخیره کن.
4. نمادهای دلخواه رو با کد نماد (nscId)، Category ID (از سفارش‌های قبلی خودت روی همون نماد قابل استخراجه) و تعداد پیش‌فرض اضافه کن.
5. هر ۵ دقیقه (یا با دکمه «بررسی فوری») سیگنال‌ها بررسی می‌شن و به‌صورت کارت در پنل «سیگنال‌های در انتظار» نمایش داده می‌شن. تایید یا رد کن.

## قدم‌های بعدی پیشنهادی

- جایگزینی موتور SMA ساده با تحلیل مبتنی بر چند اندیکاتور یا فراخوانی یک مدل زبانی.
- افزودن گزارش پوزیشن‌های باز به داشبورد.
- در صورت وجود API رسمی الگوریتمی از سمت آگاه، مهاجرت به اون API به‌جای این نسخه reverse-engineered.
